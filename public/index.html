    On your phone

    Open this address in Safari or Chrome on the phone. iPhone: Share, then Add to Home Screen. Android: the browser menu, then Add to Home screen or Install app. It then opens full screen, like an app, and works without a connection. Same numbers: the icon opens this same browser copy.

    Saved data

    Data is stored in this browser on this device only. Nothing is sent anywhere. A second copy is kept here in case the first goes missing, and is loaded on its own if so. It does not move to other devices. Clearing site data removes both, so only a backup file survives that. A backup is your own copy of numbers and receipts.

    Backup

    Back up regularly, and before clearing or resetting. Keep the file somewhere safe or paste the text into a note.

    Spreadsheet

    Every plan month as one table: pay, jars, goals, balance. Opens in Sheets or Excel. Read-only: edits there do not change this page.

    Cloud backup

    Encrypted on this device with a recovery code before anything is sent. Nobody else can open it, including the person who shared this page. New phone, or browser cleared: enter the code and the numbers come back.

    Use a recovery code

    Loading replaces the numbers here with the cloud copy and keeps this device in sync with it.

    Restore

    Restore replaces the numbers and receipts here with the copy. Back up first to keep what is here. To start from zero use Zero all.

    If numbers look empty after clearing the browser or switching devices, restore your latest copy.
